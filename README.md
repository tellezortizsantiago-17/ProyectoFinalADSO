# 📦 Gestor de Inventario y Ventas

## 🎯 Product Goal
Desarrollar un sistema interactivo por consola en Java que permita gestionar el inventario de una tienda, controlar el stock en tiempo real, procesar ventas y generar reportes financieros mediante el uso de Programación Orientada a Objetos y colecciones, garantizando un manejo seguro de los datos durante su ejecución.

## 🛠️ Tecnologías y Metodología
* **Lenguaje:** Java (Aplicación de consola)
* **Paradigma:** Programación Orientada a Objetos (POO)
* **Colecciones:** ArrayList, HashSet, HashMap
* **Gestión de Proyecto:** Scrum (GitHub Projects)
* **Control de Versiones:** Git y GitHub

## 🚀 Alcance por Sprints
* **Sprint 1 (Estructura Base):** Creación de clases (`Producto`, `Inventario`), registro de productos y consulta general de inventario.
* **Sprint 2 (Lógica de Negocio):** Implementación de ventas, actualización de precios y manejo de excepciones (`try-catch`).
* **Sprint 3 (Reportes y Filtros):** Búsqueda específica por categorías, listado de categorías únicas y generación de reporte financiero total por categoría.

## ⚙️ Cómo ejecutar el proyecto
1. Clonar el repositorio localmente usando: `git clone <url-del-repositorio>`
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Compilar y ejecutar el archivo `Main.java`.
4. Interactuar con el menú numérico directamente desde la terminal.
